# Taller-pandas-olimpiadas-grupox

## Descripcion general:
Este proyecto busca analizar los datos históricos de los Juegos Olimpicos desde Atenas 1896 hasta Río 2016 mediante Pandas en Google Colab y un trabajo colaborativo en GitHub. Se experimentó con los datos disponibles sobre atletas y países a los cuales se les realizaron transformaciones, cálculos estadísticos y gráficos para una mejor ilustración de resultados.

## Objetivos  
-	Conocer los datos disponibles en la base 
-	Implementar nuevas variables y transformar datos para una mayor comprensión
-	Comparar la relación entre participaciones y la obtención de medallas según las variables disponibles
-	Ilustrar los resultados en gráficas 
-	Comprender mejor el funcionamiento de GitHub 
## Intrucciones 
1. Clonar el repositorio
2. Descargar los datos desde Kaggle y guardarlos en data/
3. Instalar las librerías necesarias (pandas y matplolib)
4. Abrir la carpeta notebooks/ y ejecutar las celdas
## Estructura del proyecto 
-	**data/:** Enlaces de los archivos de Kaggle e instrucciones 
-	**docs/:** PDF en el que se encuentra el informe final 
-	**notebooks/:** notebook en formato .ipynb con el proceso de análisis
-	**outputs/:** Carpeta donde se encuentran las tablas y los gráficos generados durante el análisis
-	**src/:** scripts de Python 
-	**.gitignore:** archivos que no se suben al repositorio
